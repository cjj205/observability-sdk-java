触发事件：
客户投诉跨地市集客专线SLA劣化：专线使用感知差、网络间歇性卡顿、丢包，业务时断时续，影响业务使用，要求排查处理（Complaint-driven）。

工作流步骤（共7个步骤）：

步骤1：投诉受理
  - 主要操作内容：WAIMO Complaint Agent 从流程中心抓取跨地市专线SLA劣化投诉工单，完成投诉受理。
  - 输出/结果：投诉工单进入端到端处置流程。
  - 跳转逻辑：进入步骤2。

步骤2：投诉识别
  - 主要操作内容：WAIMO Complaint Agent 识别投诉现象与投诉意图，判定投诉场景。
  - 输出/结果：输出投诉现象和投诉意图（传输专线质差投诉场景）。
  - 跳转逻辑：进入步骤3。

步骤3：定界定位
  - 主要操作内容：WAIMO Complaint Agent 依次核查专线业务状态与网络情况（业务状态、路由、告警），输出定界结论；随后按技能「专线投诉诊断」检索注册中心，获取传输投诉处理智能体。
  - 输出/结果：定界结论为「传输大网线路问题」；确定 Transport Complaint Agent（传输工作台，技能：任务规划/并行调度/综合研判）承接诊断任务。
  - 跳转逻辑：定界结论为传输大网线路问题，进入步骤4。

步骤4：根因定位
  - 主要操作内容：WAIMO 向 Transport Complaint Agent 下发投诉诊断任务。传输工作台执行数据关联（按专线业务源宿端接入网元明确所属SPN网络智能），按技能「专线故障定位·抢通」检索注册中心，获取 East-GD NETSpirit（粤东SPN网络智能）与 West-GD NETSpirit（粤西SPN网络智能），动态编排并双侧并行下发诊断任务。双侧完成根因定位后，传输工作台进行根因总结并回传 WAIMO，WAIMO 将工单根因回传流程中心。
  - 输出/结果：形成跨地市协同诊断结论（故障根因、根因位置、修复建议），回传 WAIMO。
  - 跳转逻辑：进入步骤5。

步骤5：问题处置
  - 主要操作内容：WAIMO Complaint Agent 调度处置，确认支持自动抢通，授权网络智能执行业务自动抢通。若抢通方案涉及动网操作（如隧道调优），传输工作台向粤西SPN发起动网操作授权（业务场景、处置类型、动网操作名称），粤西新增授权策略并返回授权结果。West-GD NETSpirit 执行抢通方案（如隧道调优），将带宽、时延、丢包越限的业务隧道调优到新的路径；抢通方案与执行结果接力上报（方案上报：粤西→传输工作台→WAIMO；结果上报：粤西→传输工作台→WAIMO）。
  - 输出/结果：动网操作授权成功；抢通方案执行成功；WAIMO 获知业务抢通完成。
  - 跳转逻辑：业务自动抢通执行成功，进入步骤6。

步骤6：修复验证
  - 主要操作内容：Transport Complaint Agent 周期查询专线业务的SLA信息，确认指标恢复；向 WAIMO 回复修复验证结果。
  - 输出/结果：专线业务SLA指标恢复正常，修复验证通过。
  - 跳转逻辑：SLA指标恢复正常，进入步骤7。

步骤7：投诉报结
  - 主要操作内容：WAIMO Complaint Agent 客户回访确认问题已解决，投诉工单闭环，处理信息回传流程中心。
  - 输出/结果：投诉工单闭环，端到端处置完成。
  - 跳转逻辑：流程结束。
